# 철스크랩 수불현황 대시보드 개선 설계

**날짜**: 2026-04-13  
**범위**: 기존 Streamlit 대시보드(dashboard/app.py) 기능 확장 — Option 1 (기존 구조 유지 + 기능 추가)

---

## 배경 및 목적

철스크랩은 회사가 고시가격을 발표하면 공급사가 자발적으로 입고하는 구조다.  
입고량 변화는 곧 가격 경쟁력 신호다.

- 입고량 감소 → 타사 대비 고시가격 경쟁력 하락 가능성
- 입고량 증가 → 타사 대비 경쟁력 양호

가격 구조:
- **유통**: 고시가격 + 지역별 운임보조비
- **MOU**: 고시가격 + 지역별 운임보조비 + MOU 인센티브(고정) + MOU 추가 인센티브(월별)
- **전용야드**: 고시가격 + 지역별 운임보조비 + 전용야드 인센티브(고정) + 전용야드 추가 인센티브(월별)
- **회수**: 고정 단가 — 가격 정책 영향 없음

정책 결정 논리:
- 유통 + MOU/전용야드 모두 감소 → **기본가 조정** 필요 (전 공급사 영향)
- MOU/전용야드만 감소, 유통 유지 → **인센티브 조정** 필요 (해당 구분만 영향)

## 섹션별 상세 설계

### 섹션 1: 월별 현황 개선

**변경 전**: 월 선택 → 실적/계획 복합 차트 1개

**변경 후**: 탭 2개로 분리

#### 탭A — 단일 월 심층 비교
- 월 선택 (기존 selectbox 유지)
- 체크박스 4개: `실적` / `계획` / `전월 실적` / `전년동월 실적`
  - 기본 체크: 실적 + 계획
- 선택된 항목만 같은 차트에 겹쳐서 표시 (선 또는 막대 혼합)
- KPI 요약 박스: 체크된 기준 대비 증감률 자동 계산 및 표시

#### 탭B — 멀티 월 나란히 비교
- 월 복수 선택 (st.multiselect, 최대 12개월)
- 보기 항목 선택: `입고` / `사용` / `재고` 중 택일 (radio)
- 선택한 월들이 나란히 붙은 그룹 막대 차트
- 사소구분 필터 적용 가능

**영향 파일**: `dashboard/app.py` (`_render_monthly_trend`), `dashboard/charts.py` (`make_monthly_chart` 확장)

---

### 섹션 2: 입고 상세 기간 비교

**변경 전**: 단일 기간 필터 → 스택 바 차트

**변경 후**: 모드 토글 추가

#### 단일 기간 모드
기존 동작 그대로 유지.

#### 기간 비교 모드
- **빠른 선택 버튼**: `전월 비교` / `전분기 비교` / `전년동기 비교`
  - 클릭 시 A기간/B기간 날짜 자동 세팅
- **직접 설정**: A기간 date_input + B기간 date_input 각각 독립 입력
- 기존 필터(사소/구분/공급사/품목/등급) 동일 적용
- 차트: A기간 vs B기간 나란히 그룹 막대
  - 증감률(%) 레이블 막대 위에 표시
  - 증가: 초록, 감소: 빨강
- 집계 단위 전환 유지: `기간합계` / `일자별` / `주차별`

**영향 파일**: `dashboard/app.py` (`_render_receipt_detail`), `dashboard/charts.py` (`make_receipt_detail_bar` 확장 또는 `make_comparison_bar` 신규)

---

### 섹션 3: 구분별 가격정책 신호 (신규)

**위치**: 입고 상세 섹션 아래, 지역별 현황 위

#### 필터
- 사소구분: 포항소 / 광양소 / 전체
- 비교 기준: `전주 대비` / `전월 대비` (radio)
- 분석 단위 탭: `구분별` / `품목×구분` / `등급×구분`

#### 메인 차트 — 구분별 입고량 변화
- 유통 / MOU / 전용야드 각각의 당기 vs 전기 그룹 막대
- 회수: 참고용 표시 (정책 영향 없음 별도 표기)
- 증감률(%) 레이블

#### 정책 신호 패널 (자동 감지)

| 조건 | 신호 메시지 |
|------|------------|
| 유통 + MOU + 전용야드 모두 감소 (임계값 이상) | 🔴 기본가 조정 검토 |
| MOU/전용야드만 감소, 유통 유지 | 🟡 인센티브 조정 검토 |
| 유통만 감소, MOU/전용야드 유지 | 🟡 기본가 소폭 조정 검토 |
| 전 구분 증가 | 🟢 현행 가격 경쟁력 양호 |
| 변화 없음 (임계값 미만) | ⚪ 유의미한 변화 없음 |

- 감소 임계값: 기본 `-5%`, 사이드바에서 조정 가능 (slider)
- 품목×구분 / 등급×구분 탭에서 드릴다운 시 해당 단위별 신호 표시

#### 신규 파이프라인 모듈: `pipeline/gubun_signal.py`

```
build_gubun_signal(receipt_df, compare='month') -> dict
  - 입력: _preprocess_receipt() 결과 DataFrame
  - 출력: {
      구분: {당기량, 전기량, 변화율},
      품목x구분: {(품목, 구분): {당기량, 전기량, 변화율}},
      등급x구분: {(등급대분류, 구분): {당기량, 전기량, 변화율}},
      신호: {level, message}  # 'red'|'yellow'|'green'|'gray'
    }
```

#### AI 챗봇 연동
- `build_graph()` 호출 시 `gubun_summary` DataFrame 추가 전달
- `ANALYSIS_SYSTEM` 프롬프트에 `gubun_summary` 변수 설명 추가
- 예시 질문 지원: "현재 MOU 입고 감소 원인은?", "어떤 구분 가격 조정이 필요해?"
