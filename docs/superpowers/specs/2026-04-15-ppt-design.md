## 슬라이드 5 — 데이터 파이프라인 및 시각화

**헤드라인**: "Excel 업로드 한 번으로 모든 분석이 자동 생성"

**데이터 처리 흐름**

```
Excel 업로드
    → 자동 표준화 (사업장명 통일, 날짜 기준 보정)
    → 일별 집계 (입고·사용·재고 누적 계산)
    → 공급사·품목·지역별 분류
    → 시각화 자동 생성
```

**처리 핵심 설계**
- 날짜 기준: 입하일시 - 7시간 (교대 근무 07:00 기준으로 하루 정의)
- 구분 분류: 공급사별 유통 / MOU / 수입 / 회수 자동 분류

**제공 화면 (스크린샷 4분할)**
1. 월간 추이 — 실적 vs 계획 비교, KPI 요약 박스
2. 입고 상세 — 기간·사소·구분·공급사·품목 필터
3. 구분별 가격정책 신호 — 전월/전주 대비 변화율 자동 감지
4. 지역별 입고 현황 — 전국 Choropleth 지도

## 슬라이드 6 — AI 챗봇

**헤드라인**: "수치를 외우지 않아도 됩니다 — 그냥 물어보면 됩니다"

**동작 방식**

```
사용자 질문
    ↓
[라우터] 질문 유형 자동 판단 (GPT)
    ├─ 단순 조회  → RAG 검색
    │              인덱싱된 수불 데이터에서 즉시 답변
    └─ 계산·집계 → 분석 실행
                   AI가 코드 생성 → 직접 계산 → 답변
```

**질문 예시**

| 질문 유형 | 예시 | 처리 경로 |
|-----------|------|----------|
| 단순 조회 | "가장 많이 납품한 공급사는?" | RAG → 즉시 답변 |
| 날짜 포함 조회 | "포항소 3월 ADS01 입고량은?" | 분석 → 계산 후 답변 |
| 집계 계산 | "계획 대비 실적 달성률은?" | 분석 → 계산 후 답변 |

**핵심 설계 원칙**

> "수불 데이터 안에 없는 내용은 절대 답하지 않도록 설계했습니다.  
> 모르면 모른다고 말하는 챗봇입니다."

## 슬라이드 7 — 시장 구매단가 자동 모니터링

**헤드라인**: "매일 아침 뉴스를 직접 찾아보지 않아도 됩니다"

**동작 방식**

```
매일 07:00 / 13:00 자동 실행
    ↓
스틸데일리 · 스크랩워치 자동 로그인 및 기사 수집
    ↓
인하 / 인상 / 동결 자동 판단 + 변동폭(원/톤) 추출
    ↓
이력 저장 → 대시보드 시각화 + AI 요약 자동 반영
```

**제공 정보 (스크린샷)**
- 타사별 구매단가 변동 이력 차트
- 등급별 단가 변동 테이블
- AI 입고 요약 연동: "현대제철 2회 인하, 포스코 1회 인상 (최근 1개월)"

> **발표 멘트**: "하루에 두 번 자동으로 시장 정보를 수집하고,  
> 입고 AI 요약에도 자동으로 반영됩니다."

## 슬라이드 9 — 기술 이슈 & 해결

**헤드라인**: "만들면서 부딪힌 문제들, 이렇게 해결했습니다"

| 이슈 | 원인 | 해결 |
|------|------|------|
| 챗봇이 "데이터 없음" 오답 반환 | 날짜 포함 조회 질문을 잘못된 경로(RAG)로 분류 | 날짜 포함 질문은 무조건 분석 경로로 라우팅 기준 명시 |
| 기사 날짜 오입력 (2025→2026) | 연도 없는 날짜 파싱 실패 → 오늘 날짜로 대체 | 기사 URL의 날짜를 기준값으로 사용하도록 수정 |
| 동결 기사가 인상으로 표시 | 본문의 "인상" 키워드를 제목의 "동결"보다 먼저 감지 | 제목의 동결·보합·유지를 먼저 확인하도록 순서 변경 |
| AI가 없는 수치를 만들어냄 (환각) | 데이터 조회 실패 시에도 AI가 추측해서 답변 | 실행 결과 검증 후 실패면 즉시 "데이터 없음" 반환 |

> **발표 멘트**:  
> "이슈를 만날 때마다 원인을 먼저 파악하고,  
> Claude와 함께 구체적인 해결 방법을 찾았습니다."

## 슬라이드 10 — 기대효과

**헤드라인**: "반복 업무는 줄이고, 판단에 집중할 수 있습니다"

**정량적 효과** (어림 추정 기준)

| 업무 | 기존 | 개선 후 |
|------|------|---------|
| 일별 수불 집계·보고 | 약 1~2시간 수작업 | 수분 내 자동 생성 |
| 시장 가격 정보 수집 | 매일 수동 검색 | 하루 2회 자동 수집 |
| 데이터 조회 | 담당자 문의 후 대기 | 챗봇으로 즉시 확인 |

**정성적 효과**
- 수불·시장가격 정보를 한 화면에서 통합 확인
- 계획 대비 실적 시각화로 구매 의사결정 근거 명확화
- 타사 구매단가 변동 이력으로 가격 협상 레버리지 확보
- 비개발자도 AI 도구로 업무 시스템 구축 가능성 확인

**향후 연동 시 추가 효과**
> 사내 서버 데이터 자동 연동 시  
> Excel 업로드 없이 실시간 데이터 반영 가능
