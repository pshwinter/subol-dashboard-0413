# 섹션 요약 보고서 설계

**날짜:** 2026-04-07  
**대상 파일:** `dashboard/app.py`

---

## 개요

월간 추이, 입고 상세 섹션 헤더 바로 아래에 `st.info()` 박스 형태로 2~3줄 요약 보고서를 표시한다. 기본은 정적 계산(pandas), API 키 입력 시 AI 자연어 요약 토글을 제공한다.

---

## 1. 월간 추이 요약

### 표시 형식

```
ℹ️ 실적 입고: 1,234,567톤 (전월 대비 +5.2%) · 실적 사용: 987,654톤 · 현재 재고: 456,789톤 · 입고 달성률: 98.2% · 사용 달성률: 101.5%
```

### 계산 기준

- **실적 입고**: `daily_chart[daily_chart["is_actual"]]["recv_qty"].sum()`
- **실적 사용**: `daily_chart[daily_chart["is_actual"]]["use_qty"].sum()`
- **현재 재고**: 실적 데이터의 마지막 날짜 기준 `inv` 합산 (사소×품목별 last 값 합산)
- **전월 대비**: 실적 마지막 달 vs 그 전달 입고량 비교. 전달 데이터 없으면 숨김.
- **입고 달성률**: `실적 입고 / 계획 입고 × 100`. 계획 데이터 없으면 숨김.
- **사용 달성률**: `실적 사용 / 계획 사용 × 100`. 계획 데이터 없으면 숨김.

### 반응성

- 현재 ITEM 필터(`item_list`, `total_prominent`), 사소 구분 토글 상태를 반영한 `daily_chart` 기준으로 계산

## 2. 입고 상세 요약

### 표시 형식

```
ℹ️ 총 입고: 234,567톤 · 입고 건수: 1,234건 · 일 평균: 12,345톤
   구분: MOU 120,000톤 · 회수 80,000톤 · 유통 34,567톤
   등급 1위: A등급(120,000톤) — 공급사 1위 (주)POSCO(80,000톤) · 2위 현대제철(40,000톤)
   등급 2위: B등급(80,000톤) — 공급사 1위 동국제강(50,000톤) · 2위 세아제강(30,000톤)
```

### 계산 기준

- **총 입고**: `filtered["입하량(net)"].sum()`
- **입고 건수**: `len(filtered)`
- **일 평균**: `총 입고 / 조회 기간 일수`
- **구분별 합계**: `filtered.groupby("구분")["입하량(net)"].sum()` → 전체 표시 (MOU·회수·유통). 해당 구분 데이터 없으면 숨김.
- **등급 순위**: `filtered.groupby("등급")["입하량(net)"].sum()` → 내림차순 상위 2개
- **공급사 순위**: 각 등급 내 `filtered[filtered["등급"]==grade].groupby("공급사")["입하량(net)"].sum()` → 내림차순 상위 2개

### 엣지 케이스

- `filtered`가 비어있으면 요약 박스 미표시
- 등급 1개뿐이면 1위만 표시
- 각 등급 내 공급사 1개뿐이면 공급사 1위만 표시
- 등급 컬럼 전체 NaN이면 등급/공급사 줄 숨김

## 3. AI 요약 (공통)

### 동작 방식

- API 키가 사이드바에 입력된 경우에만 "AI 요약" 체크박스 표시
- 체크박스 ON → `_ai_summary(summary_text, api_key)` 호출 → GPT가 2문장 이내 한국어 요약 생성
- 결과는 `st.caption()`으로 `st.info()` 박스 바로 아래 표시

### 캐시 전략

- `@st.cache_data(ttl=300)` — 동일 입력값에 대해 5분간 캐시하여 중복 API 호출 방지
- 캐시 키: 요약 텍스트 문자열 (수치가 바뀌면 자동 무효화)

### LLM 프롬프트

```
당신은 철강 공장 수불 현황을 요약하는 전문가입니다.
아래 현황 수치를 바탕으로 2문장 이내 한국어로 핵심을 요약하세요.
수치는 그대로 사용하고, 추측하지 마세요.

[현황]
{summary_text}
```

## 4. 구현 범위

- **변경 파일**: `dashboard/app.py` 단독
- **신규 함수**:
  - `_monthly_summary(daily_chart) -> str` — 월간 추이 요약 텍스트 생성
  - `_receipt_summary(filtered) -> str` — 입고 상세 요약 텍스트 생성
  - `_ai_summary(summary_text, api_key) -> str` — LLM 자연어 요약 (캐시 적용)
- **삽입 위치**:
  - 월간 추이: `st.header("월간 추이")` 직후
  - 입고 상세: `st.header("입고 상세")` 직후, 필터 위젯 이전
