        |
        v

        |
        v

    |  (1) 월간 추이        실적 vs 계획 비교  |
    |  (2) 입고 상세        기간·품목·공급사   |
    |  (3) 가격정책 신호    전월/전주 변화율   |

  [ 동작 방식 ]

    사용자 질문
        |
        v
    +-------------------------+
    |  라우터 (GPT 자동 판단) |
    +----+--------------------+
         |
         +----------------------+
         |                      |
         v                      v
    [ 단순 조회 ]          [ 계산·집계 ]
    RAG 검색               분석 실행
    인덱싱된 데이터        AI 코드 생성
    에서 즉시 답변         -> 직접 계산
                           -> 답변 반환

  [ 질문 예시 ]

    +-------------------------+-----------+---------------------------+
    |  질문                   |  경로     |  결과                     |
    +-------------------------+-----------+---------------------------+
    |  가장 많이 납품한       |           |                           |
    |  공급사는?              |  RAG      |  즉시 답변                |
    +-------------------------+-----------+---------------------------+
    |  포항소 3월             |           |                           |
    |  ADS01 입고량은?        |  분석     |  계산 후 답변             |
    +-------------------------+-----------+---------------------------+
    |  계획 대비              |           |                           |
    |  실적 달성률은?         |  분석     |  계산 후 답변             |
    +-------------------------+-----------+---------------------------+

  [핵심 원칙]
    "수불 데이터 안에 없는 내용은 절대 답하지 않도록 설계.
     모르면 모른다고 말하는 챗봇입니다."

  헤드라인: "반복 업무는 줄이고, 판단에 집중할 수 있습니다"

  [ 정량적 효과 -- 어림 추정 기준 ]

  +---------------------+---------------------+---------------------+
  |  업무               |  기존               |  개선 후            |
  +---------------------+---------------------+---------------------+
  |  일별 수불 집계     |  약 1~2시간 수작업  |  수분 내 자동 생성  |
  |  시장 가격 수집     |  매일 수동 검색     |  하루 2회 자동 수집 |
  |  데이터 조회        |  담당자 문의 후     |  챗봇으로 즉시      |
  |                     |  대기               |  확인               |
  +---------------------+---------------------+---------------------+

  [ 정성적 효과 ]

    (1)  수불·시장가격 정보를 한 화면에서 통합 확인
    (2)  계획 대비 실적 시각화 -> 구매 의사결정 근거 명확화
    (3)  타사 단가 변동 이력 -> 가격 협상 레버리지 확보
    (4)  비개발자도 AI 도구로 업무 시스템 구축 가능성 확인

  [ 향후 연동 시 추가 효과 ]

    |  -> Excel 업로드 없이 실시간 데이터 반영 가능         |
