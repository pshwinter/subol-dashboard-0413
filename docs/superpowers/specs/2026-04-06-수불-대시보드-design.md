## 3. 데이터 흐름

```
Excel 파일 2개
  → loader.py       : LoadedData dataclass 생성
  → transform.py    : 컬럼 표준화 + Wide→Long 변환
  → metrics.py      : 일별 입고/사용/재고 집계 (실적+예상)
  → supplier.py     : 공급사-기준정보 매칭, 공급사별 집계
  → dashboard/app.py: Streamlit 렌더링 + Excel 다운로드
  → report/exporter : 수불현황 시트 + 공급사 시트 Excel 생성
```

## 4. 데이터 모델

### LoadedData (dataclass)

```python
@dataclass
class LoadedData:
    receipt: pd.DataFrame      # 입고 실적
    usage: pd.DataFrame        # 사용 실적
    exp_receipt: pd.DataFrame  # 예상입고량 (Long format 변환 후)
    exp_usage: pd.DataFrame    # 예상사용량 (Long format 변환 후)
    opening: pd.DataFrame      # 기초재고
    ref: pd.DataFrame          # 기준정보 (공급사-ITEM 매핑)
```

### 표준화 규칙 (transform.py)

- 사소구분: `광양` / `포항` → `광양소` / `포항소` 통일
- 날짜: 모든 datetime → `date` 타입 통일
- 수량 컬럼: float 통일, NaN → 0
- 예상 데이터: Wide format → Long format (melt)

### 재고 계산 (metrics.py)

```
실적 기간:
  당일 재고 = 기초재고 + cumsum(입고 실적) - cumsum(사용 실적)

예상 기간 (실적 미집계일):
  당일 재고 = 마지막 실적 재고 + cumsum(예상입고) - cumsum(예상사용)

집계 단위: 사소 × ITEM × 날짜
is_actual 컬럼: True(실적) / False(예상) 구분
```

### 공급사 매칭 (supplier.py)

```
입고 실적 LEFT JOIN 기준정보 (공급사명 기준)
미매칭 공급사 → '기타' 분류
결과: 공급사 × ITEM × 사소 × 날짜별 입고량
```

## 5. 대시보드 구성 (Streamlit)

### 사이드바 (전역 필터)

- 사소 선택: 포항소 / 광양소
- 집계 기준: 전체 합산 / 품목별

### [섹션 1] 월간 추이 복합 차트

**차트 구성 (Plotly)**
- 선그래프: 일별 입고량 — 실적(실선), 예상(점선+연한색)
- 선그래프: 일별 사용량 — 실적(실선), 예상(점선+연한색)
- 막대그래프: 일별 재고량 — 실적/예상 색상 구분
- X축: 날짜, 실적↔예상 경계 수직선 표시

**차트 상단 필터**
- 집계 기준 토글: 일자별 합계 / 아이템별
- 아이템별 선택 시: ITEM 멀티셀렉트

**하단 데이터 테이블**
- 컬럼: 날짜 | 입고(실적) | 입고(예상) | 사용(실적) | 사용(예상) | 재고

### [섹션 2] 입고 상세 탭

**필터**
- 기간: 날짜 범위 선택 (st.date_input)
- 사소: 포항소 / 광양소 / 전체
- 공급사: 멀티셀렉트
- 품목(ITEM): 멀티셀렉트
- 등급: 멀티셀렉트

**표시 내용**
- 필터 적용된 입고 원본 데이터 테이블
- 공급사별 입고량 가로 막대 차트 (Plotly)

### [다운로드]

- 페이지 하단 Excel 다운로드 버튼 (st.download_button)
